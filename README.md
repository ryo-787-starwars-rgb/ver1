# ATLAS — Bodybuilding PFC Rebalance

## 更新内容
- 「高タンパク・低脂質すぎて糖質が不足する」という問題を是正。
- 緩やかな増量：P 2.2 g/kg、F 0.7 g/kg、C は残りのカロリー、維持カロリー+7.5%。
- 維持：P 2.2 g/kg、F 0.7 g/kg、C は残りのカロリー、維持カロリー相当。
- 減量：P 2.4 g/kg、F 0.6 g/kg、C は残りのカロリー、維持カロリー-15%。
- 推奨値・エネルギー比率・FOOD上部の1日PFCゲージを新設定に連動。
- CAL、TRAIN、スーパーセット、コンパウンドセット、食品161種類、既存食事記録・身体記録等は維持。

## 体重86kg、維持2,600kcalの例（維持カロリーを直接設定した場合の理論値）
| モード | kcal | P | F | C |
|--|--:|--:|--:|--:|
| 増量 | 2,795 | 189g | 60g | 375g |
| 維持 | 2,600 | 189g | 60g | 326g |
| 減量 | 2,210 | 206g | 52g | 230g |

**アプリ内の維持カロリーは、体重×活動係数（27/30/33）で概算**するので、86kg・係数30なら2,580kcal。上の2,600kcalの例とは若干異なります。活動量設定は体重推移を参考に調整してください。

本設定はIFBB公式の基準ではなく、個人の身体変化やコンディションに応じて調整してください。更新前にDATAタブでJSONバックアップを保存してください。
