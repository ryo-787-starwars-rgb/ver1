# MISSION REACHER v2.0

iPhone用個人PWA。HTML/CSS/JavaScript、ビルド不要。データはブラウザのlocalStorageに保存され、サーバーには送信しません。

## GitHub Pagesへの更新
1. 既存のv1アプリの「STATS/PROGRESS」でJSONバックアップを書き出す。
2. ZIPを解凍し、フォルダ内の `index.html`, `app.js`, `sw.js`, `icon.svg`, `manifest.webmanifest` を既存GitHubリポジトリのルートにアップロードし、同名ファイルを上書きしてCommit。
3. Settings → Pagesの設定はそのまま。公開URLも変わりません。
4. 数分待ち、Safariで再読み込み。必要ならホーム画面のアプリを終了して再起動。

## 主な機能
- 胸/背中/肩/二頭/三頭/脚/体幹 × 5種類のプラン、種目追加・代替種目の自由入力
- セットごとに重量/回数/RIR/完了、休憩タイマー
- 筋力グラフ（推定1RM/最大重量/最大セット負荷）、身体計測グラフ
- 最終目標と4週間先の短期目標目安、線形トレンドの到達日予測
- 食材100gあたりの参考PFC、グラム数、食費、月予算、自由入力
- JSONバックアップ・復元、v1の同一オリジンlocalStorageからの初回移行（可能な範囲）

## 注意
- v1とv2はデータ構造が異なります。v1 JSONはv2の復元画面に直接インポートできません。**必ずv1をバックアップ**し、同じURLでv2を開くと自動移行を試みます。
- v1のセッションは記録形式によって一部の情報が移行できない場合があります。
- 予測は少数の実測データに対する単純な線形回帰で、停滞・減量・測定誤差などを十分にモデル化していません。到達保証や医療判断には使用しないでください。
- PFCは参考値で、食品表示や調理法で変動します。
- iPhone Safariのサイトデータを消すと記録が失われるため、定期的にJSONを書き出してください。
