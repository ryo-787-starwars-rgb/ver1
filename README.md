# ATLAS — 定番食品アップデート（2026-11-05）

既存の ATLAS をベースに、食品データを日常的な定番食材中心に拡充しました。旧食品の配列位置を保持しているため、旧版からの入力互換性を考慮しています。保存キー `mission-reacher-v2` は変更していません。

- FOOD の食材初期選択は空欄、食事入力を最上部に配置。
- 定番食品をジャンル別に追加（食品総数は自動テストで確認）。
- 追加食品の数値は100gあたりの**参考・概算値**であり、公的成分表との個別照合済みデータではありません。商品ラベル優先。
- 既存のTRAIN・BODY・CAL・STATS・DATAの機能は維持。
- GitHub Pagesの更新前に DATA からJSONバックアップを保存してください。
- iPhone実機Safariでの動作検証は未実施です。

アプリ用ファイルは `app.js`, `index.html`, `icon.svg`, `manifest.webmanifest`, `sw.js` です。
