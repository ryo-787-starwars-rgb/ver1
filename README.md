# MISSION REACHER v1.0

個人用・無料で動作するPWAの初期版です。React/TypeScriptではなく、依存パッケージ不要のHTML/CSS/JavaScriptで実装しています。これによりビルドなしで試せます。

## 収録機能
- 月・木・土・日の筋トレメニュー、重量・回数・セット完了、前回記録、休憩タイマー
- 食事PFC、カロリー、食費、目標値
- 体重・腹囲・腕周り、簡易グラフ
- 朝夜モビリティとタイマー（朝メニューは仮）
- JSON形式のバックアップ・復元
- ローカル保存、PWAオフラインキャッシュ

## 無料でiPhoneに入れる
1. このフォルダのファイルをGitHubリポジトリにアップロードする（公開リポジトリの場合は**コードは公開**されます。個人の記録データはアップロードされません）。
2. GitHub Pagesを有効化する（Settings → Pages → Deploy from a branch → main / root）。無料公開URLが発行されます。
3. iPhoneのSafariでURLを開き、共有 → ホーム画面に追加。
4. ホーム画面から起動し、記録する。

**注意**：ログイン機能はありません。URLを知っている人も画面にアクセスできるので、URLそのものを秘密の認証として扱わないでください。記録は各端末のブラウザ内に保存され、他端末とは同期しません。Safariのデータ削除・端末故障に備え、PROGRESS画面からJSONを定期的に書き出してください。

## ローカルで試す
Pythonがあればフォルダ内で `python3 -m http.server 8000` を実行し、Macで `http://localhost:8000` にアクセスします。PWAのインストールにはHTTPSのホスティングが必要です（localhostは開発例外）。
