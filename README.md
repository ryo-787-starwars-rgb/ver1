# ATLAS · FOOD ダッシュボード更新（2026-11-06）

## 変更点
- FOODの順番を **1日のPFCゲージサマリー → 食材の入力・食事履歴 → 目標PFCの設定** に変更。
- kcal、タンパク質、脂質、炭水化物の摂取量・目標値・差・進捗ゲージを常時表示。食事の追加・編集・削除と目標再計算で更新。
- FOOD内の食材検索、ジャンルタブ、選択中の食材、ボタンのiPhone横はみ出しを修正。
- トレーニング消費量の任意補正は折りたたみ式で、PFC目標設定の前に配置。補正機能自体は維持。
- TRAIN / STATS / CAL / GOALS / DATAの機能・表示は変更なし。
- データの保存キーはそのまま。既存データのJSONバックアップを先に取得してください。
